# C - Hello, World

This directory contains low-level programming projects in C focusing on the basics, compilation, preprocessor steps, and standard output.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files are compiled on Ubuntu 20.04 LTS using `gcc` (or `clang` on macOS)
* All your C files should end with a new line

## Tasks

### 0. Preprocessor
* **File:** `0-preprocessor`
* **Description:** A shell script that runs a C file (specified by the `$CFILE` environment variable) through the C preprocessor without compilation, saving the output into a file named `c`.
