# Simple Calculator in C

A command-line calculator program built as part of the Holberton School low-level programming curriculum. This project demonstrates foundational C programming concepts including control structures, user input handling, and strict adherence to coding standards (Betty style, C89/gnu89).

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Compiled on Ubuntu 20.04 LTS using `gcc` with options: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All code files adhere strictly to the **Betty coding style**.

## Files

| File Name | Description |
|-----------|-------------|
| `calculator.c` | Main program implementing the welcome menu, user choice selection, and quit functionality. |

## Compilation

To compile the program, run the following command in your terminal:

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 calculator.c -o calculator
