# C - More functions, more nested loops

This project is part of the low-level programming curriculum at Holberton School. It focuses on further practicing functions, nested loops, and character classification checks in C.

## Requirements
- Allowed editors: vi, vim, emacs
- All files will be compiled on Ubuntu 20.04 LTS using gcc, using the options -Wall -pedantic -Werror -Wextra -std=gnu89
- All your files should end with a new line
- Your code should use the Betty style (checked using betty-style.pl and betty-doc.pl)

## Tasks

### 0. isupper
* File: 0-isupper.c
* Description: Writes a function that checks for uppercase characters and returns 1 if uppercase or 0 otherwise.
