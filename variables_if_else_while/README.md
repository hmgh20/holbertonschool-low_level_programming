# C - Variables, if, else, while

This project is part of the Holberton School low-level programming curriculum. It introduces foundational concepts in C programming, including variable declarations (`char`, `int`, `unsigned int`), arithmetic, relational and logical operators, conditional statements (`if`, `else`), and loops (`while`).

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compilation environment: Ubuntu 20.04 LTS using `gcc`
- Compiling flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All files must end with a new line
- Code must adhere to the **Betty** coding style guidelines (`betty-style.pl` and `betty-doc.pl`)

## Tasks
* **0. Positive anything is better than negative nothing** (`0-positive_or_negative.c`): A C program that assigns a random number to the variable `n` each time it is executed, printing whether the number is positive, zero, or negative.
