# C - Functions, nested loops

This project is part of the Holberton School low-level programming curriculum. It focuses on learning how to write custom functions, use nested loops, manage header files, and utilize the custom `_putchar` function in C (C89 standard, Betty style compliant).

## Description of Files

| File | Description |
|------|-------------|
| `_putchar.c` | Contains the custom `_putchar` function implementation using the `write` system call. |
| `main.h` | Header file containing the prototype for `_putchar` and any other project function prototypes. |
| `0-putchar.c` | A program that prints `_putchar`, followed by a new line, returning 0 on success. |

## Requirements
- Allowed editors: `vi`, `vim`, `nano`
- Compiled on Ubuntu 20.04 LTS using `gcc` with options `-Wall -pedantic -Werror -Wextra -std=gnu89`
- Code must follow the **Betty** coding style.
